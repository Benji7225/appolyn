# Appfigures (appfigures.com) — fiche du 2026-11-19

Méthode : appfigures.com, capterra.com, g2.com, toolradar.com sont inaccessibles en WebFetch (ENOTFOUND). Tout vient de WebSearch (extraits de pages, souvent d'agrégateurs ou de concurrents). Les chiffres sont donc à revérifier sur la page officielle. Les sources concurrentes (Sonar, AppSprint, AppTweak, AppFollow, Appbot) sont marquées comme partisanes.

## Positionnement
- Plateforme d'analytics et d'intelligence d'apps : téléchargements, revenus, abonnements, avis, classements, dépenses pub, en un tableau de bord multi-stores. Source : résumés WebSearch de Stork (https://www.stork.ai/en/appfigures) et SoftwareOne (https://platform.softwareone.com/product/app-intelligence/PCP-0373-3610).
- Stores couverts : iOS App Store, Mac App Store, Google Play, Amazon Appstore ; Steam cité par Stork (source peu fiable, pages à dates incohérentes). Source : https://appfigures.com/analytics/integrations/ios-app-store, https://appfigures.com/analytics/integrations/amazon-appstore, https://appfigures.com/analytics/integrations/mac-app-store.
- Ancienneté : « depuis 2008 » selon un comparatif (https://blog.apps.deals/astro-vs-respectaso-appfigures-apptweak-aso-tools-mac, via WebSearch). Une seule source, non vérifiée.
- ASO = module parmi d'autres, plus limité que les outils ASO purs (avis du résumé WebSearch, sources tierces). La page d'accueil dédiée s'intitule « Intuitive ASO Tools to Get More Downloads » (https://appfigures.com/aso).
- Plusieurs offres produit : Store Performance, Apple Ads Intelligence, SDK Intelligence, Review Management, ASO Tools. Sources : https://app.appfigures.com/products/store-performance, https://app.appfigures.com/products/apple-ads-intelligence, https://app.appfigures.com/products/sdk-intelligence, https://app.appfigures.com/aso-tools.
- Cibles : indés jusqu'aux entreprises (paliers jusqu'à Amplify, voir Prix). Pas de déclaration de cible officielle lue.

## Fonctionnalités page par page
Seuls les titres et extraits de pages ont été vus ; le contenu détaillé de chaque écran n'est pas lu.
- Analytics / Store Performance : revenu net, revenu brut, remboursements, impressions App Store pour iOS ; classements de catégorie mis à jour toutes les heures dans le palier gratuit. Source : https://appfigures.com/analytics/integrations/ios-app-store ; https://www.appfigures.com/pricing (extrait WebSearch).
- Rapport d'avis unifié (Unified Reviews Report), gratuit ; alertes avis par e-mail et Slack ; réponse aux avis depuis la plateforme ; traduction. Source : https://appfigures.com/platform/pricing et Stork JA (https://www.stork.ai/ja/appfigures). Réponses IA aux avis : mention isolée sur la page allemande de Stork, non confirmée.
- ASO Tools : suivi de rang de mots-clés (mises à jour horaires), découverte de mots-clés classés, Keyword Inspector (vue temps réel des résultats d'un mot-clé sur App Store ou Google Play), Keyword List Optimizer pour le champ 100 caractères d'Apple, Competitor Keywords. Source : https://help.appfigures.com/en/category/reports-tools-95ufv3/.
- Plateformes ASO : App Store (iPhone, iPad) et Google Play dans le monde entier. Source : https://help.appfigures.com/en/article/what-platforms-does-appfigures-support-for-app-store-optimization-1mabqr7/.
- Suggestions de mots-clés par IA et découverte de mots-clés liés par IA. Source : https://assets.appfigures.com/pricing (extrait WebSearch).
- Apple Ads Intelligence : mots-clés qui génèrent des installs chez les concurrents, pour baisser le coût Apple Search Ads. Source : https://app.appfigures.com/products/apple-ads-intelligence ; martech.zone (https://martech.zone/appfigures/).
- SDK Intelligence : SDK installés ou retirés par n'importe quelle app. Source : https://app.appfigures.com/products/sdk-intelligence ; martech.zone.
- Rapports et alertes : rapports par e-mail, alertes temps réel, envoi des derniers téléchargements et revenus vers Slack. Source : WebSearch (agrégateurs).
- API ouverte pour l'accès programmatique. Source : agrégateurs ; https://appfigures.com/platform/pricing mentionne un accès programmatique.
- Outils d'avis : sélecteur de dates et export Excel (.xlsx) annoncés sur le blog, non datés. Source : https://blog.appfigures.com/category/new-features/page/3.
- Écrans exacts, filtres, rapports personnalisés, exports hors avis : non trouvé.

## Onboarding
- Parcours : création de compte puis connexion des comptes store ; « une fois connecté, importe données d'apps, téléchargements, revenus, avis, classements » (WebSearch, agrégateurs). Détail des écrans, durée, import historique : non trouvé.
- Palier gratuit « Starter » existe (toolradar, https://toolradar.com/tools/appfigures/pricing, via WebSearch). Un avis G2 note que les données de ventes ne se rafraîchissent pas automatiquement en gratuit (résumé WebSearch G2).
- Courbe d'apprentissage citée comme première plainte (voir Reproches).
- Application mobile iOS officielle (https://apps.apple.com/ca/app/appfigures/id962408539).

## Prix et paliers
Sources divergentes, à vérifier sur https://www.appfigures.com/pricing.
- Gratuit : Starter, analytics de base, accès limité (Stork, toolradar).
- Entrée : « Connect » à 9,99 $/mois, ou 7,99 $/mois en annuel (toolradar, via WebSearch). Un comparatif d'indés cite aussi 9,99 $ ; un autre, 69 $/mois (Sonar, partisan, non vérifié).
- Monitor : 5 apps, puis 1,99 $ par app supplémentaire, 25 mots-clés, 0 concurrent premium ; 44,99 $/mois sur la page officielle ; un ancien instantané indiquait 35,99 $/mois (résumé WebSearch).
- Optimize : 119,99 $/mois dans un instantané, 149,99 $/mois (500 mots-clés) dans un autre. Mises à jour horaires et intelligence complète réservées aux paliers supérieurs.
- Boost : 449,99 $ ou 599,99 $/mois selon l'instantané.
- Amplify : 999,99 $ ou 1 399,99 $/mois selon la source.
- Un calculateur toolradar cite 2 500 mots-clés pour un palier, incohérent avec la page officielle ; l'auteur du résumé le jugeait douteux.
- Remise annuelle exacte : non trouvé. Essai gratuit : non trouvé.
- Pages de prix multiples : /pricing, /analytics/pricing, /platform/pricing, ce qui explique les instantanés contradictoires. Source : résultats WebSearch.

## Ce que les utilisateurs louent (avec sources)
- Analytics consolidées, suivi de mots-clés, analyse concurrentielle, navigation simple. Source : G2 (https://www.g2.com/products/appfigures, via WebSearch).
- Réponse aux avis depuis la plateforme et tableau de bord unique pour plusieurs fiches. Source : G2, via WebSearch.
- Graphiques cumulés et empilés pour repérer les tendances (un avis G2).
- Abordabilité et recherche de mots-clés (comparatif G2 Adjust vs Appfigures : https://www.g2.com/compare/adjust-vs-appfigures).
- Notes : G2 4,0/5 (18 avis) selon une page de comparaison ; 4,2/5 (17) selon AppFollow ; 4,8 (5 avis) sur un ancien instantané ; Capterra 4,5/5 (4 avis). Divergence liée à la date.
- Un modèle gratuit pour le rapport d'avis unifié (page de prix).

## Ce que les utilisateurs reprochent (avec sources)
- Courbe d'apprentissage : trop de fonctions pour un débutant (G2).
- Support jugé décevant dans des avis récents (G2).
- Fonctions jugées insuffisantes pour le prix (G2) ; trop cher pour qui veut seulement suivre ses rangs : un utilisateur de longue date est parti (cité par AppDrift, concurrent : https://appdrift.co/blog/best-aso-tools-reddit).
- Toksta : « pas adapté aux revenus faibles » (https://www.toksta.com/products/appfigures, mise à jour août 2025).
- Qualité des données : panne de collecte des notes Apple d'environ 17 heures le 22 avril 2025 ; incident de sur-déclaration de ventes Apple (isdown, pingoru : https://isdown.app/status/appfigures/incidents/383347-apple-ratings-collection).
- Peu de réseaux pub ; données de ventes non automatiques en gratuit (G2).
- ASO moins profond que les outils dédiés (AppTweak page alternative : https://www.apptweak.com/en/alternative-to-appfigures, partisan).
- Aucun fil Reddit direct trouvé ; Toksta compte 4 fils et 30 commentaires, sentiment neutre.

## Stratégie SEO
- Domaine séparé entre marketing et app (app.appfigures.com reflète les mêmes pages) : doublons de pages /pricing indexés sur plusieurs sous-domaines (app., assets., analytics., cf.). Source : résultats WebSearch.
- Pages produit : /aso, /aso-tools, /products/store-performance, /products/apple-ads-intelligence, /products/sdk-intelligence, /analytics/pricing, /platform/pricing.
- Pages d'intégration par store (programmatique léger) : /analytics/integrations/{ios-app-store, mac-app-store, amazon-appstore}.
- Guides longs : « ASO Keyword Research: 9 Steps for the App Store & Google Play » (https://app.appfigures.com/resources/aso/keyword-research). Hub « Resources » avec « Insights Today » (actualités de l'industrie, ex. https://appfigures.com/resources/insights/20230721), le blog a migré vers ce hub (blog.appfigures.com).
- Centre d'aide public indexé (help.appfigures.com) : article « which platforms support ASO ».
- Pages de rapport publiques par app : https://appfigures.com/reports/app-profile/337268224471/update-timeline (page « update timeline » par application, signe de pages programmatiques sur des milliers d'apps).
- Outils gratuits : rapport d'avis unifié gratuit ; outil de mots-clés gratuit autonome : non trouvé.
- Mots-clés visibles : « ASO tools », « app store optimization », « ASO keyword research », « app analytics ». Volumes : non trouvé.
- Cible d'articles tiers « alternatives à Appfigures » : Sonar (https://trysonar.app/blog/best-appfigures-alternatives-for-aso), Appbot (https://appbot.co/alternatives/appfigures-alternatives/), AppTweak, AlternativeTo.

## Pour Appolyn
- Copier : intégrations par store en pages dédiées ; rapport d'avis gratuit comme produit d'appel ; hub de ressources ASO long format ; alertes Slack ; CLI/API pour agents IA.
- Faire mieux : un onboarding en quelques minutes pour indés (la courbe d'apprentissage est la plainte n°1) ; un tarif d'entrée lisible et unique (contre 3 pages de prix aux chiffres contradictoires) ; un support réactif ; ASO + publication multi-langues, que l'ASO d'Appfigures ne couvre pas (aucune publication de fiche trouvée).
- Éviter : l'escalade tarifaire par mots-clés et par app (plainte « trop cher pour mon revenu ») ; les doublons de pages sur plusieurs sous-domaines ; des fonctions que l'indé n'ouvrira jamais (SDK Intelligence).
